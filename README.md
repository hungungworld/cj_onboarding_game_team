# ONLYONE 레시피를 찾아라: 팀 대항전

CJ제일제당 신입 온보딩용 웹 방탈출 게임의 **동시 접속·팀 대항** 버전 (비공식 포트폴리오)
혼자 하는 원본은 `cj_onboarding_game` 저장소에 그대로 있습니다.

- 조원이 같은 입장 코드·조 이름으로 들어오면 한 판을 같이 진행합니다.
- 방마다 단서가 조원에게 나뉘고, 2막은 과반 투표, 3막 역할은 입장 순서대로 자동 배정됩니다.
- 소통 창: 우리 조 채팅 · 전체 채팅 · 조별 현황, 그리고 다른 조에 SOS를 보내고 도와주는 상생 점수.
- 진행자 화면 `host.html`: 회차 열기(입장 코드), 전체 공지, 조별 현황, 100주년 메시지 벽.

설계와 운영 방법: [`../team-game-design.md`](../team-game-design.md)

## 실행
```bash
node tools/serve.js
```
- 진행자: http://localhost:5173/host.html 에서 **회차 열기** → 입장 코드 4자리
- 참가자: http://localhost:5173/?s=입장코드
- 혼자 테스트할 때 같은 브라우저의 탭 두 개는 같은 사람으로 잡혀요. `localhost`와 `127.0.0.1`처럼 주소를 다르게 열면 다른 사람이 됩니다.
- 시작 화면의 **장면 바로 가기**는 서버 없이 혼자 보는 데모 모드예요.

> `index.html`을 더블클릭해서 여는 방식(file://)은 브라우저에 따라 이미지·스크립트가 막힐 수 있으니 위 방법을 쓰세요.

## 서버 (Supabase)
- 프로젝트: `cj-onboarding-team` (서울 리전, 무료 요금제)
- 연결 정보: `js/config.js` (주소와 공개 키 두 줄. 다른 프로젝트로 바꿀 때 여기만 고침)
- DB 구조·보안·함수: `supabase/schema.sql` (새 프로젝트의 SQL Editor에 그대로 붙여 실행)
- 무료 요금제는 7일 동안 쓰지 않으면 일시 정지돼요. **교육 전날 Supabase 대시보드에서 깨워 두세요.**

## 구성
| 파일 | 내용 |
|---|---|
| `js/content.js` | 퍼즐 문구, 정답 해시, 힌트, 등장인물, 말풍선 화자, 안내 팝업 문구 (내용 수정은 여기서만) |
| `js/game.js` | 게임 엔진. 맨 위에 조 공유 상태 동기화, 아래쪽에 단서 나눔·투표·역할 배정·소통 창 |
| `js/net.js` | 실시간 연결: 입장, 조 상태 주고받기, 접속자, 메시지 |
| `js/host.js` · `host.html` · `css/host.css` | 진행자 화면 |
| `tools/simulate.js` | 3개 조 × 5명 봇 시뮬레이션: `node tools/simulate.js` (게임 1분 = 3초, `SEED=숫자`로 다른 판). 진짜 서버에 들어가 플레이하고 결과표를 출력. 진행 중에는 `host.html?timescale=20`으로 지켜볼 수 있음 |
| `css/style.css` | 디자인. 맨 아래에 텍스트 배치 규칙과 접근성 색이 모여 있음 |
| `assets/` | cj.co.kr에서 받은 로고·브랜드 카드 28종·연혁 사진 |
| `tools/hash.js` | 정답을 바꿀 때 해시 만들기: `node tools/hash.js 새정답` |
| `tools/serve.js` | 로컬 미리보기 서버 |

## 서체와 로고
- 서체: **CJ ONLYONE** (cj.co.kr에서 쓰는 웹 글꼴). `assets/fonts`에 300·400·600·700 굵기를 넣어 함께 배포해서, CJ 서체가 없는 PC·휴대폰에서도 같은 글꼴로 보입니다. 제목은 700을 씁니다.
- 로고: cj.co.kr 상단 로고 원본 SVG를 그대로 씁니다.
  - `assets/ci/cj_logo_black.svg`: 검은 글자, 밝은 상단바용
  - `assets/ci/cj_logo_white.svg`: 흰 글자, 시작 화면(사진 위)용
- CJ제일제당 제출·시연용 비공식 포트폴리오라서 CJ 자산을 그대로 썼습니다. 다른 곳에 공개할 때는 서체·로고 사용 권한을 먼저 확인하세요.

## 문구를 고칠 때
- **팝업**은 `lines: [...]` 줄 배열로 씁니다. 줄끼리 글자 수 차이는 30% 이내로 맞춥니다.
- **본문**(방 소개, 증언, 단서, 말풍선)에는 줄바꿈을 넣지 않습니다. 넣어도 화면에서 무시되고, 너비에 맞춰 자동으로 감깁니다.
- **대사**는 `{ who: "블라썸", text: "..." }` 형태로 쓰면 말풍선으로 나옵니다. 따옴표는 쓰지 않습니다.
- "20개가", "+1분", "CJ제일제당" 같은 묶음은 자동으로 끊기지 않게 처리됩니다.

자세한 규칙: [`../ui-text-layout-rules.md`](../ui-text-layout-rules.md)
